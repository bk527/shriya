* Your Pull Request will be reviewed before it can be merged.

# Git Submission

Once you've completed the quiz:

```text
Answer the questions
       ↓
Edit the answer file
       ↓
git status
       ↓
git add .
       ↓
git commit
       ↓
git push
       ↓
Create Pull Request
       ↓
Code Review
       ↓
Merge
```

## Submission Checklist

* [ ] All questions answered
* [ ] Changes added using `git add`
* [ ] Changes committed
* [ ] Changes pushed to GitHub
* [ ] Pull Request created
* [ ] Pull Request reviewed
* [ ] Pull Request merged
